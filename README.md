# Məsud Kitab Evi

Bu qovluqdakı fayllar GitHub Pages üçün tam hazırdır.

## GitHub-da açmaq

1. GitHub-da yeni repository yaradın.
2. `index.html`, `styles.css`, `script.js` və `og.png` fayllarını repository-nin əsas hissəsinə yükləyin.
3. **Settings → Pages** bölməsinə keçin.
4. **Deploy from a branch**, sonra **main** və **/(root)** seçib **Save** basın.

Sayt bir neçə dəqiqədən sonra verilən `github.io` ünvanında açılacaq.

Kitablar `script.js` faylındakı `books` siyahısında saxlanılır. Yeni kitab əlavə etmək üçün eyni quruluşda yeni sətir əlavə edin.
