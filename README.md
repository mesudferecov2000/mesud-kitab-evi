# KitabEvi - statik kitab sayti

Bu proyekt birbasa `index.html` ile acilir ve GitHub Pages-de isleyir.

Fayllar:
- `index.html` - esas sehife
- `style.css` - dizayn
- `script.js` - axtaris, filtr, sebet, sevimliler, modal ve s.
- `assets/covers/` - her kitab ucun lokal ehtiyat uzluk sekli

GitHub Pages:
1. Fayllari repository-nin kokune yukleyin.
2. Settings -> Pages -> Deploy from a branch secin.
3. Branch: main, folder: / (root).
4. Save edin.

Qeyd: Kitab uzlukleri ucun Open Library HTTPS linkleri istifade olunur. Link acilmasa, lokal SVG uzluk avtomatik gosterilir. Buna gore sekilsiz kart qalmir.
